小麥注音使用說明

智慧學習版（Linux／fcitx5）。從 fcitx 選單的「使用說明」可以再次開啟本頁。

安裝與設定

安裝

適用 Ubuntu 24.04 與 Linux Mint 22。下載 .deb 檔後，在下載的資料夾執行：

sudo apt update
sudo apt install fcitx5 fcitx5-config-qt ./fcitx5-mcbopomofo-smart-learning_@MCBOPOMOFO_PACKAGE_VERSION@_amd64.deb
im-config -n fcitx5
  • 登出再登入後，開啟「Fcitx 5 設定」，在「輸入法」頁籤加入「小麥注音」（自動選字）或「傳統注音」（打一字選一字）。
  • Linux Mint（Cinnamon）不需要額外套件。
  • Ubuntu（GNOME）要另外安裝並啟用 GNOME Shell 擴充套件「Input Method Panel」，候選字窗才會顯示在正確位置：先 sudo apt install gnome-shell-extension-manager，再開啟 Extension Manager 搜尋安裝。
  • 本套件會取代原本的 fcitx5-mcbopomofo 套件。

候選字面板主題

套件附了兩個候選字面板主題：「小麥注音淺色」（mcbopomofo-light）與「小麥注音深色」（mcbopomofo-dark），配色和 Mac 版的候選字面板相同。主題要自己選用：開啟「Fcitx 5 設定」→「附加元件」→「經典使用者介面」→「設定」：

  • 淺色：「主題」選「小麥注音淺色」，不勾「跟隨系統淺色/深色設定」。
  • 深色：「主題」選「小麥注音深色」，不勾「跟隨系統淺色/深色設定」。
  • 跟隨系統：「主題」選「小麥注音淺色」、「深色模式」選「小麥注音深色」，勾選「跟隨系統淺色/深色設定」。
  • 勾選「在主題與桌面支援時使用系統重點色」時，反白的候選字跟著桌面的強調色。
  • 字級：主題不指定字型，請在同一頁的「字體」設定字型與大小（例如 Noto Sans CJK TC 24）。

主題是 fcitx 全域的設定，會套用到所有輸入法。面板是直角、沒有毛玻璃效果；選字鍵和候選字同一個字級。Ubuntu GNOME 使用「Input Method Panel」擴充套件時，候選字窗由擴充套件與 GNOME 的主題決定，這兩個主題不適用。

與 Mac 共用詞庫

詞庫資料夾可以指到同步資料夾，和 Mac 或其他 Linux 電腦共用詞彙與學習紀錄。以 Synology Drive 為例：

  1. 安裝 Synology Drive Client for Linux，建立同步工作，把 NAS 上的 McBopomofo 資料夾同步到本機，例如 ~/SynologyDrive/McBopomofo。
  2. 等第一次同步完成（資料夾內的 data.txt 等檔案都已出現）。
  3. 在小麥注音的偏好設定把「詞庫資料夾（與其他電腦共用）」設為該資料夾。
  4. 切換一次輸入法讓設定生效。

自選的資料夾裡不會自動建立範本檔，以免和還在同步的檔案衝突。資料夾還沒同步完成時，會顯示等待同步的提示。

基本操作

  • 打注音、按聲調（一聲按 空白）就會組字，打完一句按 Enter 送出（主鍵盤或數字鍵盤的 Enter 都可以）。
  • 選字：游標停在要改的字上，按 空白 或 ↓ 開啟候選字，按選字鍵選字。
  • fcitx 選單（系統匣圖示或面板上的選單）最上方可以直接切換「注音－標準鍵盤」與「注音－許氏鍵盤」。
  • 許氏鍵盤的數字鍵不是注音，打中文時直接按數字，數字會跟中文一起留在組字區。
  • Caps Lock 打開時打出的是小寫英文，關掉回到注音。
  • 打錯字時按 Esc：只清掉字尾打錯的亂碼，見下方「Esc 清除亂碼」。

Esc 清除亂碼

打太快難免會打出一串不是中文、也不是英文的字。按一下 Esc 只會清掉字尾的亂碼，保留到最後一個完整的中文字或英文單字，不用再一個一個按 Backspace。

今天開會 jqvx今天開會
寄給 email 了 ;/z寄給 email 了
hellojkqhello
下午 3 點 ㄒㄧ下午 3 點
  • 會清掉的：還沒打完的注音、不成單字的英文字母、字尾的符號和空白。
  • 會保留的：中文字、英文單字（英文字典裡有的或打過的字）、數字。
  • 英文字母前段是單字時保留單字，例如 hellojkq 留下 hello。
  • 清完後組字區下方會提示「再按一次 Esc 清除全部」；連按兩下 Esc 清除整個組字區。
  • 字尾沒有亂碼時，第一下只會顯示提示，不會清掉任何字，避免誤刪整句。
  • 游標不在最後面時，清的是游標前面的亂碼。

本功能預設開啟，可在偏好設定關閉「按 ESC 只清除字尾打錯的亂碼」，回到原本的行為。

智慧中英切換

不用按 Shift 或 Caps Lock 也能中英數混打：打的鍵組不成注音時，會自動變成英文。

你用過這個 app?你用過這個 app?
ChatGPT 很好用ChatGPT 很好用
2026 年2026年
ok?ok?

什麼時候變成英文

  • 同一個注音位置又按了一次，例如 app（ㄇㄣ 之後又按 ㄣ）。
  • 組出來的注音不是字，例如 you 加空白（ㄗㄧㄟ 不是字）。
  • 按大寫字母，直接開始英文，例如 ChatGPT。
  • 注音還沒打完就接數字或符號，例如 ok?。

回到中文

  • 按 空白、任何符號或 Backspace 就回到中文。
  • 只打了數字時，空白只會回到中文、不插入空白，所以 2026 空白 年 會是「2026年」。
  • 英文打完也可以不按空白，直接接著打中文：打完一個字的注音和聲調，就會自動轉回中文，例如 hello 接 ㄏㄠˇ → 「hello 好」、PDF 接 ㄉㄤˇ → 「PDF 檔」。前面要是英文單字（或 PDF 這類大寫縮寫），而且整串不是英文單字或單字的開頭，才會轉換。
  • 英文和中文一起留在組字區，按 Enter 一起送出。

很短的英文可能剛好是合法注音，例如許氏鍵盤的 a 加空白會打成「疵」，這時請改用 Shift 或 Caps Lock。本功能可在偏好設定關閉。

中英混打細節

中英文之間自動加空格

中文後面接英文、英文後面接中文時，自動在中間加一個空格。

你好hello你好 hello
用iPhone拍用 iPhone 拍
  • 數字不加空格，例如「2026年」「3個」。
  • 用 Backspace 把英文刪光時，自動加的空格也一起刪掉。

英文、數字後的標點用半形

緊接在英文字母或數字後面的標點自動打半形，接在中文後面的維持全形。

價格是300.價格是300.
好,好，

想在英文、數字後面打全形標點，請按住 Ctrl 再打標點，例如 Ctrl+, 一律是「，」。

英文大小寫修正

英文打完按 空白 時，像 iPhone、OpenAI 這類中間有大寫的字，即使打成小寫也會自動改正。

iphone 空白iPhone
openai 空白OpenAI
  • 想保留小寫就按 Enter 送出，不會修正。
  • 除了內建的常見字（iPhone、macOS、GitHub、YouTube……），你用大寫打過兩次以上的字（例如 ButyPOS）也會自動修正。
  • 只有字首大寫（Apple）或全大寫（NASA）的字不會修正。

以上三項都可以在偏好設定個別關閉。

英文聯想

打英文時（或注音還沒打完時）按 Tab，列出英文單字補完，按選字鍵選。

ass Tabass、assad、assam、assay、asses、asset、assoc、assail…
hel Tabhel、held、hell、helm、help、helen、helga、helix、hello…
  • 清單第一個是原本打的字，選它等於不改。
  • 打過兩次以上的英文字會排在最前面，例如 ChatGPT。
  • 跳著打也找得到打過的字，例如 aocd 找到 associated。
  • 英文字典是系統的 /usr/share/dict/american-english（套件 wamerican），加上你打過的字。
  • 組字區是空的時候，Tab 照常交給程式。

數字與算式

數字快打

按 ` 後輸入數字，列出各種格式，按選字鍵或 Enter 送出。

` 2023.09.072023年9月7日（星期四）、二〇二三年九月七日、中華民國112年9月7日、2023/09/07…
` 112.9.7民國年也可以，同上
` 12:3012時30分、下午十二點三十分、下午12點30分、12:30 PM…
` 65486,548、陸仟伍佰肆拾捌元整、六千五百四十八、6,548元…
` 10*15/625、10*15/6=25、10×15÷6=25、貳拾伍元整…

中文模式直接算

在組字區打算式再按 =，答案會自動接在後面。全形、半形運算子都可以，數字中間的「。」當小數點。

(2+3)*3=（2＋3）＊3＝15
3.5*2=3。5＊2＝7

常用句

同一句送出三次，就會記住這句。之後在句首或標點後打出開頭兩個字以上，組字區下方會提示後半句，按 Tab 整句接上。

謝謝 Tab謝謝您的耐心等候
  • 句子要 6 到 40 個字（英文單字算一個字），不能有標點；有標點時會分成幾句分別記。
  • 約三個月沒用到會自動忘掉，用得越多次留得越久。
  • 記住的句子存在詞庫的 learning/sentences/，多台電腦（Mac 與 Linux）共用。
  • 可以在「管理詞彙」的常用句分頁查看、刪除，或直接加入句子（立即生效、不會被遺忘）。偏好設定「記住常打的句子，打出開頭按 Tab 接上」可關閉。

候選字調整

在候選字視窗反白某個字詞時：

  • + 或 =：提高排序，以後優先出現。
  • - 或 _：排除，以後不再出現。單字也可以，例如排除「你」，打 ㄋㄧˇ 就會先出現「妳」。
  • ?：用辭典查詢。

提高排序和排除都會先跳出確認；調整的結果可以在「管理詞彙」的中文詞彙、排除詞彙分頁改回來。符號與英文不能調整。

文字範本

  • 按 ` 後輸入代碼，例如地址、帳號等常用文字，按選字鍵或 Enter 送出。
  • 文字範本（按 ` 列出的清單）在「小麥注音」模式使用；在「傳統注音」模式按 ` 會開啟符號表。
  • 範本放在詞庫資料夾的 text-templates.txt，一行一筆：代碼、Tab、內容，內容要換行請寫 \n。
  • 在 fcitx 選單「管理詞彙…」的「文字範本」分頁新增、修改、刪除。
  • 詞庫在預設資料夾時，第一次使用會建立附範例的檔案；自選的資料夾不會建立，以免蓋掉其他電腦還在同步的檔案。

符號表與 emoji

  • 按兩次 `（或在範本中再按一次 `）開啟分類符號表。
  • 打完標點按 空白 或 ↓，也會開啟符號表，反白停在剛打的標點。
  • 兩鍵選符號：第一鍵選列（左側標示），第二鍵選格；按 Backspace 回到選列。
  • 內建表情、手勢、愛心、動植物、食物、生活、天氣、符號等 emoji 分類。
  • 符號表放在 symbol-table.txt，一行一類：分類名稱、Tab、以空白分隔的符號；從選單「編輯符號表」開啟。檔案不存在時用內建的符號表；從選單開啟時，會先把內建的符號表寫成檔案，方便修改。

自動學習

  • 選字記憶：選過的字會記住前後文，下次同樣的句子優先出現。
  • 暫存詞：兩個字以上的詞手動選過 1 次，就收進暫存詞，不分前後文都優先出現；30 天沒再用到會自動清除。
  • 個人詞庫：暫存詞之後再打出來送出一次，就寫進個人詞庫（data.txt），永久生效。
  • 拆詞學習：內建詞被拆開改字，例如「許是」改成「許氏」，同樣選兩次後會把新詞記下來。
  • 學習資料存在詞庫資料夾的 learning/，詞庫放在同步資料夾（例如 Synology Drive）時，多台電腦（Mac 與 Linux）共用並合併。
  • 不想要的詞可以從選單「編輯排除的詞彙」排除，排除後不會再被自動加回來。

管理詞彙

從 fcitx 選單「管理詞彙…」開啟，或從桌面的應用程式選單開啟「小麥注音管理詞彙」，不用再直接編輯文字檔。分頁：

  • 中文詞彙：自訂詞優先出現在候選字。輸入詞會自動帶出注音，破音字可以自己改。
  • 排除詞彙：永遠不會出現在候選字的詞。
  • 英文詞彙：英文聯想（Tab）優先列出的字；打過兩次以上的字會自動列在這裡。
  • 常用句：已記住和還在累積次數的句子。
  • 暫存詞：選過一次、還在 30 天期限內的詞，可以刪除或直接加入中文詞彙。
  • 文字範本：按 ` 後輸入代碼插入的內容。
  • 「在檔案管理員中顯示」按鈕會在檔案管理員中選取目前分頁的檔案（學習資料的分頁是 learning/ 資料夾）。
  • 改好的內容立即生效，不用重新啟動輸入法。視窗切回前景時，會重新讀取其他電腦同步過來的變更。
  • 自動帶出注音時，簡體字不會先轉成繁體，請直接輸入繁體字詞。
  • 從應用程式選單開啟、而這台電腦的小麥注音還沒啟動過時，會以唯讀方式開啟；先在 fcitx 啟用小麥注音一次，或從 fcitx 選單開啟即可修改。

在一台電腦刪除的英文字、常用句、暫存詞，其他電腦（Mac 與 Linux）也會一起刪除。

浮動組字窗

有些程式會在組字途中自己改動內容，造成漏字或補字重複（常見於網頁裡的編輯器）。遇到這種程式，在 fcitx 選單勾選「此程式使用浮動組字窗」：組字中的字改顯示在 fcitx 面板最上方，按 Enter、標點等送出時才交給程式。

  • 設定是以程式為單位，例如在 Chrome 勾選後，整個 Chrome 都會使用。再點一次取消。
  • 切換時，正在組字的內容會先送出。
  • 已勾選的程式列在偏好設定「使用浮動組字窗的程式」，也可以在那裡刪除。
  • 組字列和候選字在同一個面板，面板在游標下方；組字列和候選字使用同一個字型大小。
  • 同一個瀏覽器用不同方式啟動時，回報的名稱可能不同。

選單沒有出現這一項時

這個功能要知道是哪個程式，而 GTK、Qt 程式只有透過 fcitx 自己的輸入模組連線時才會回報程式名稱。沒有回報名稱的程式（部分 Wayland 原生程式也是）不會出現這一項，打字照常，只是不能使用浮動組字窗。

  1. 在終端機執行 echo $GTK_IM_MODULE $QT_IM_MODULE。如果顯示的不是 fcitx fcitx（例如是空白），程式就沒有使用 fcitx 的模組，不會回報名稱。fcitx5-diagnose 的輸出也會看到這種程式的程式名稱是空的。
  2. 在 ~/.xprofile 加入下面兩行（要所有使用者都生效，改在 /etc/environment 加入 GTK_IM_MODULE=fcitx 與 QT_IM_MODULE=fcitx）： 
    export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
  3. 登出再登入，之後新開的程式就會回報名稱。GTK、Qt 的 fcitx 模組（fcitx5-frontend-gtk3、fcitx5-frontend-gtk4、fcitx5-frontend-qt6）需已安裝，一般安裝 fcitx5 時會一起裝好。

不想改環境變數，或程式仍沒有回報名稱時，可以改用 fcitx 本身的「切換內嵌預編輯區域」快速鍵（預設 Ctrl+Alt+P，可在「Fcitx 5 設定」→「全域選項」查看或更改）：在出問題的輸入框按一下，組字就不在程式內顯示、改在 fcitx 面板上。這個快速鍵只對目前的輸入框有效，不需要程式名稱。

「切換內嵌預編輯區域」是 fcitx 自己的設定；浮動組字窗只影響勾選的程式，不會改變它。

中英提示與模式圖示

  • 中英切換提醒：按 Caps Lock 時，會以 fcitx 通知短暫顯示「ABC」或「中文」。有些桌面環境不會把 Caps Lock 鍵交給輸入法，這時不會出現提醒。
  • 模式狀態顯示：使用小麥時，fcitx 選單（系統匣或面板）會多一項「中／英」（Caps Lock 或智慧切換的英文模式時為「英」）。也可以讓半形標點那一項改顯示「全／半」，點一下切換。

偏好設定

從「Fcitx 5 設定」→「輸入法」→ 選「小麥注音」→ 按「設定」開啟（fcitx 系統匣選單的「設定」也可以）。本版新增的項目：

  • 按 ESC 只清除字尾打錯的亂碼：按一下只清除字尾打錯的亂碼、連按兩下清除全部（預設開）。
  • 智慧中英切換：不按 Shift、Caps Lock 也能打英文（預設開）。
  • 中英文之間自動加空格、英文、數字後的標點用半形、按空白時修正英文大小寫（預設都開）。
  • 記住常打的句子，打出開頭按 Tab 接上：常用句（預設開）。
  • 中英切換提醒：開啟／關閉（預設開）。
  • 中／英模式圖示（預設開）、全／半形模式圖示（預設關）。
  • 詞庫資料夾（與其他電腦共用）：見「詞庫檔案」。
  • 使用浮動組字窗的程式：見「浮動組字窗」。

候選字面板的淺色、深色與字級，見「候選字面板主題」。

詞庫檔案

預設的詞庫資料夾是 ~/.local/share/fcitx5/mcbopomofo/，可在偏好設定改成同步資料夾，例如 Synology Drive 的 McBopomofo 資料夾。

  • data.txt：個人詞庫，一行一筆「詞 注音」，注音之間以 - 連接。
  • exclude-phrases.txt：要排除的詞。
  • text-templates.txt：文字範本。
  • symbol-table.txt：符號表。
  • learning/：選字記憶、temporary/ 暫存詞、english/ 打過的英文字、sentences/ 常用句，每台電腦各寫自己的檔案；removed.txt 記錄刪除的項目，讓其他電腦一起刪除。

同步工具產生的衝突副本不會被讀取。

快速鍵一覽

  • `：文字範本、數字快打；再按一次開啟符號表。
  • Tab（英文時）：英文聯想。
  • Tab（有常用句提示時）：接上後半句。
  • + - ?（候選字視窗）：提高排序、排除、查辭典。
  • =（算式後）：自動算出答案。
  • Caps Lock：切換英文小寫。
  • Shift + 字母：直接打英文。
  • Ctrl + 標點：一律打全形標點。
  • 輸出簡體中文：由 fcitx 的繁簡轉換外掛（套件 fcitx5-chinese-addons）提供，fcitx 選單裡有切換項目，快速鍵預設 Ctrl+Shift+F，可在該外掛的設定修改。
  • 切換半形標點：從 fcitx 選單切換。
  • Esc：清除字尾打錯的亂碼，保留最後一個完整的中文或英文字；候選字視窗開著時關閉視窗。
  • Esc Esc（連按兩下）：清除整個組字區。

按住 Alt 或 Super 的組合鍵，輸入法不處理，直接交給程式。
